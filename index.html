01why

One query, fourteen sources, one ranked list.

qany runs your query against public search, news, code, package, and paper indexes. It removes duplicate URLs, fuses the rankings with Reciprocal Rank Fusion, and adjusts the order with query overlap, source intent, and what you have read before.

No keys.

Free, with no account. qany calls endpoints that already answer browsers.

Fourteen sources.

DuckDuckGo, Brave, Bing, Bing News, Mwmbl, Right Dao, Hacker News, Wikipedia, MDN, Stack Overflow, GitHub, npm, arXiv, and OpenAlex.

Three surfaces.

The same binary runs as a CLI, an HTTP API, and an MCP server for Claude Code, OpenCode, Claude Desktop, and other clients.

Readable pages.

qany fetch extracts readable text, falls back to the Wayback Machine, and adds what it reads to a local BM25 corpus.

When not to use it. qany is a poor fit if you need sub-second latency or an SLA, if you run high query volume or pool IPs, if you need semantic search over a curated index, or if you need compliance guarantees. A paid API will beat qany on vague or invented-word queries.

--jsonPrint one line of JSON.
--no-cacheSkip the search cache.

shell 
qany search "sqlite fts5 bm25" -n 5
qany more https://bun.com/docs/runtime/html-rewriter
qany fetch https://bun.com/docs/runtime --max-chars 4000
qany serve -p 8787

Question-shaped searches rerank automatically. When every engine returns nothing, qany retries once with DuckDuckGo's autocomplete suggestion. Set QANY_CACHE_DIR to move the cache, QANY_NO_CACHE=1 to disable it, and QANY_NO_LEARN=1 to stop recording pages in the local corpus.

04connect

Point your agent at it.

qany speaks MCP over stdio. It also serves a local HTTP API. There is no hosted account and no token exchange.

shell 
claude mcp add --transport stdio qany -- bunx @qexle/qany@0.3.0 mcp

Add --scope user to enable qany for all your projects, or --scope project to write .mcp.json into the current project. The default scope covers this project only.

.mcp.json 
{
  "mcpServers": {
    "qany": {
      "command": "bunx",
      "args": ["@qexle/qany@0.3.0", "mcp"]
    }
  }
}
shell 
opencode mcp add qany -- bunx @qexle/qany@0.3.0 mcp

shell 
curl "http://localhost:8787/search?q=bun+htmlrewriter"
curl "http://localhost:8787/search?q=bun+htmlrewriter&n=5&format=json"
curl "http://localhost:8787/fetch?url=https://example.com&max_chars=4000&format=json"

The server binds to 127.0.0.1, so it answers only requests from this machine. It returns text/plain by default and JSON with format=json. Missing parameters return 400. Engine or fetch failures return 502 with the reason.

Any MCP client. Spawn bunx @qexle/qany@0.3.0 mcp and speak newline-delimited JSON-RPC 2.0 on stdin and stdout. qany implements tools/list, tools/call for search, more, recall, and fetch, server/discover for MCP 2026-07-28, and the legacy initialize handshake.

05how

A retrieval system with its own ranking.

qany runs fourteen engines and ranks the merged result itself, with Reciprocal Rank Fusion, a relevance vote and a freshness tie-break.

Fuse the rankings.

qany dedupes by normalized URL and applies Reciprocal Rank Fusion. Query overlap, local corpus reads, domain trust, and query intent adjust the final order. The rarest word in the query carries the most weight.

Guard the edges.

If an engine's top three results share no word of three or more characters with the query, qany drops that engine's set. The guard catches challenge pages that masquerade as results.

Read the question twice.

Question-shaped queries split into up to three reading angles. qany fetches the top pages, reorders them by page evidence, then searches once more for vocabulary the query lacks.

Stay polite.

qany serializes requests per host, waits between calls, and retries with jittered backoff. DuckDuckGo and Brave get benched for 10 minutes after a challenge. The bench survives restarts.

Remember locally.

Every page qany reads joins a BM25 index capped at 600 pages. Later searches read from the corpus, so your reading history can move a result.

Fetch with a fallback.

qany extracts readable text and falls back to the Wayback Machine or cache. The (direct), (wayback), or (cache) tag tells you which route answered.

Add a source.

Implement the Engine interface, add the engine to the list in src/search.ts, and build the parser against a saved fixture. src/engines.ts has 14 worked examples.

src/types.ts 
export interface Engine {
  name: string;
  minIntervalMs: number;
  search(query: string, num: number): Promise<SearchResult[]>;
}
06limits

The honest part.

qany is free because it reads public endpoints. That trade shows up in four places.

Throttling.

DuckDuckGo and Brave sometimes serve challenge pages. qany benches the challenged engine, serves a stale cache entry when it has one, and falls back to the Wayback Machine when a page fails. GitHub allows 10 repository searches a minute per IP.

One machine.

Run qany from one machine. Don't pool IPs or put it behind a large shared service. The endpoints will notice, and the cooldowns will get longer.

Privacy.

Queries go to public search engines. The cache and reading corpus stay in ~/.cache/qany. There is no qany account and no qany server in the middle.

Version 0.3.0.

Command and tool names can change until 1.0.
